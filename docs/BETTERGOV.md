# Publishing to BetterGov Open Data Portal

Target: https://data.bettergov.ph/datasets (Education category is currently empty).

## Suggested listing
- **Title:** CHED Memorandum Orders (CMO) Index (2000–2026)
- **Publisher:** Commission on Higher Education (source) / community compilation
- **Category:** Education
- **Formats:** CSV, JSON Lines
- **Resources:**
  - `data/cmo_index.csv`
  - `data/cmo_index.jsonl`
  - optional: this GitHub repo as `source_url`
- **License:** CC0 for the index; attribute CHED for underlying documents
- **Description:** Derived catalog of CHED CMOs with year, number, title, category heuristic, and PDF URLs. Does not host PDF binaries.

## Submit via
1. GitHub issue/PR on https://github.com/bettergovph/open-data-portal
2. Email: volunteers@bettergov.ph
3. Discord: https://discord.gg/bettergovph
